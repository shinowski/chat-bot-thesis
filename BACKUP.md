# Integrated Flamma project

The main branch contains the complete working project published on October 20, 2026.
The earlier October 9 snapshot remains on `backup/full-flamma-2026-10-09`.

- `Flamma/`: chatbot, active intent-model manifest and artifacts, tests, and built frontend.
- `Image/thesis-backend/`: integrated image backend and all four existing image checkpoints.
- Root README and scripts: setup, startup, stopping, and online sharing.

Clone the default branch and follow the first-time setup in README.md. The checked-in frontend build can be used without rebuilding, but frontend editing requires Node.js.
Run share.ps1 to generate a new temporary online link on your own computer.

Saved chats, uploads, session secrets, API keys, local environments, logs, downloaded tunnel tools, and reproducible embedding caches are excluded.
